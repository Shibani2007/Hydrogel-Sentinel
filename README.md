# COSSEN — Coastal Settlement Resilience Pipeline

**COSSEN** is a small, open-source demonstration pipeline supporting a community resilience initiative for coastal settlements in West Bengal. It models simple data ingestion, validation, and transformation for project monitoring indicators (rainwater systems, mangrove restoration, cold storage usage, training placements).

## Contents
- `src/` application code
- `data/` sample input and expected output
- `tests/` unit tests
- `ARCHITECTURE.md` system design
- `docs/` deployment notes
